# 日記開頭的 YAML

宇宙裡的每一顆星，都來自一篇日記開頭的這幾行。原本的數位分身就是靠它們，才讀得懂二十多年的記憶。

```markdown
---
title: 京都的雨
date: 2016-07-15
category: travel
characters: [阿哲]
places: [京都]
themes: [旅行與異鄉, 創作與藝術]
summary: 在小書店躲雨，決定重新為自己拍照。
mood: 平靜
---

和阿哲去京都。一連下了五天雨……
```

| 欄位 | 用途 | 沒寫的話，工具怎麼補 |
| --- | --- | --- |
| `title` | 星星的名字 | 第一個標題列，或第一句話，最後才用檔名 |
| `date` | 星星在銀河裡的位置（越往外越接近現在） | 檔名裡的日期（`2016-07-15.md`、`20160715.md`）→ 內文開頭的「2016年7月15日」→ 檔案修改時間 |
| `category` | 顏色與旋臂；也是左側軌道面板的一軌 | 子資料夾名稱（`travel/`、`work/`）→ 關鍵字 → `diary` |
| `characters` | 人物，會成為恆星 | 你在第 2 步確認的人名 |
| `places` | 地方 | 你在第 2 步確認的地名 |
| `themes` | 主題，會成為星座 | 內建主題字典的關鍵字 |
| `summary` | 點星星時看到的一句話 | 內文第一個完整的句子（40 字內） |
| `mood` | 心情 | 情緒字詞出現最多的那一種 |

## 分類（category）

內建的分類與旋臂：

| key | 名稱 | 旋臂 |
| --- | --- | --- |
| `love` | 愛與家 | 內側 |
| `life` | 生活 | 內側 |
| `diary` | 日記 | 內側 |
| `thinkings` | 思索 | 內側 |
| `travel` | 旅行 | 外側 |
| `work` | 工作 | 外側 |
| `study` | 學習 | 外側 |
| `create` | 創作 | 外側 |
| `screen` | 電影與書 | 外側 |
| `tech` | 科技 | 外側 |

`category` 寫 key 或中文名稱都可以。想加自己的分類，改 `builder/pipeline.js` 最上面的 `CATEGORIES`。

## 小提醒

- 一篇一個檔案，`.md` 最好；`.txt` 和 `.docx` 也能讀，下載時會變成 `.md`。
- 清單用 `[a, b]`，或一行一個 `- a`。
- 原本就有的欄位一律保留，工具只補缺的。
